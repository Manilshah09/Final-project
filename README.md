Data Intelligence Dashboard
About the Project

This project is an Excel-based Data Intelligence Dashboard created using a sales transaction dataset.

It analyzes sales, customers, products, regions, and transaction trends using Excel formulas, PivotTables, PivotCharts, and data analysis tools.

Main Features
Total Revenue and Transaction KPIs
Customer and product analysis
Regional sales analysis
Monthly sales trend
Product category analysis
High-value customer identification
Most sold product identification
Premium customer filtering using FILTER
Conditional Formatting with icons
Scenario Manager and Goal Seek
Linear Regression analysis
Timestamp using NOW()
Date and Time functions
Slicers and Timeline for interactive filtering
Interactive Dashboard
Workbook Sheets
Final Project Dataset – Original transaction data
Analysis – Formulas, KPIs, customer/product/region analysis
Analytical Conclusions – Key findings and insights
Regression Analysis – Linear regression results
Scenario Summary – Scenario Manager results
Visualizations – PivotTables and PivotCharts
Dashboard – Final interactive dashboard
